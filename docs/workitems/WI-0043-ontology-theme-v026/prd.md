### 6.1 FR-1 토큰 대조 (AC1)
방법: 두 HTML의 `<style>` 안 CSS에서 주석을 지우고 선택자 · 변수 이름별 값을 뽑았습니다. 같은 선택자를 다시 정의하면 뒤 값이 이기므로 그 규칙대로 유효값을 잡았습니다(`:root` 블록이 두 개이며 앞은 옛 청록 `#15C7C7`, 뒤가 v1 `#326ADA`). 변수 밖에 직접 쓴 색은 hex · rgba 값 집합으로 따로 비교했습니다. 비교 스크립트는 저장소에 넣지 않았습니다.

| 항목 | v0.24 | v0.26 | 결과 |
|---|---|---|---|
| 유효 `:root` 변수 | 64개 | 64개 | 값 차이 0 |
| CSS 안 hex 값 집합 | - | - | 한쪽에만 있는 값 0 |
| CSS 안 rgba 값 집합 | - | - | 한쪽에만 있는 값 0 |
| CSS 크기(내장 글꼴 제외) | 276,382 B | 322,350 B | +45,968 B, 화면 컴포넌트 증가 |
| `o-*` 클래스 | - | - | v0.26에만 169개, v0.24에만 0개 |

- 비교가 실제로 차이를 잡는지: v0.26 사본의 `--key: #326ADA` 한 글자를 `#326ADB`로 바꿔 같은 스크립트에 넣으면 그 한 줄만 차이로 나옵니다.
- ontology 프리셋(`packages/axis-tokens/src/brands/ontology/light.json`, 1.3.0)의 라이트 색 17개 가운데 16개가 v0.26 `:root` 값에 있습니다. 나머지 `#5F6673`은 WI-0025 D1의 AA 보정값(원본 `sub` #6B7280, 부록 B)이라 의도된 차이입니다.
- 다크: 프로토타입에는 다크 값이 없습니다(v0.24 · v0.26 모두). WI-0025 부록 A의 다크 값은 디자인 시스템 v1 문서에서 왔으므로 이 대조로는 확인할 수 없고, 묶음에도 다크 변경 언급이 없습니다.
- 결론: 차이 0건, 후속 patch 없음. 디자인 오너의 「토큰 변경 없음」 진술과 일치합니다.
