# WI-0061 릴리스 노트: 레지스트리 비교를 항목 내용 기준으로

> 작성일: 2026-10-24 | WI: WI-0061 | GitHub: #167 | changeset: `@axis-ds/cli` · `@axis-ds/mcp` patch

## 변경 사항

- 원격 레지스트리와 포함본을 `version` 이 아니라 항목별 sha256 으로 비교해요. ui-react 만 릴리스해 version 만 오른 경우 더는 안내가 뜨지 않아요
- 내용이 실제로 다르면 「내용이 다른 항목이 N개 있습니다(…)」로 다른 항목 이름을 5개까지 알려요. 원격을 우선 쓰는 동작은 같아요
- 항목에 sha256 이 없어 비교할 수 없으면 종전처럼 version 으로 판정해요
- mcp 도 같은 공유 코어를 써서 같은 규칙이 적용돼요

## 남겨 둔 것

- 저장소에 커밋된 `apps/web/public/r/index.json` 의 version 이 publish 때 재생성한 값과 어긋나는 문제(WI-0045 의 결정 대기 항목)는 그대로예요. 이번 변경으로 그 어긋남이 사용자 안내로 드러나지는 않아요
